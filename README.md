# Ứng dụng Quản lý Thời gian

## Giới thiệu
Ứng dụng Quản lý Thời gian được xây dựng nhằm hỗ trợ người dùng theo dõi, quản lý và tối ưu hóa thời gian làm việc cá nhân.

## Mục tiêu
- Quản lý công việc theo thời gian
- Theo dõi tiến độ và thời gian thực hiện
- Hỗ trợ người dùng lập kế hoạch hiệu quả

## Kiến trúc hệ thống
Hệ thống được xây dựng theo mô hình kiến trúc ba lớp (3-tier architecture):
- Tầng trình bày (Frontend)
- Tầng xử lý nghiệp vụ (Backend)
- Tầng dữ liệu (MySQL)

## Công nghệ sử dụng
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
- Cơ sở dữ liệu: MySQL
- Quản lý mã nguồn: GitHub (Git Workflow)

## Hướng phát triển
- Hoàn thiện giao diện người dùng
- Bổ sung chức năng thống kê và báo cáo
- Triển khai ứng dụng thực tế
